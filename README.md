# 花样年华照看所

以花样年华为灵感的非官方同人像素经营 Demo。照看所与对话均为架空创作。

## 开始体验

用静态服务器打开根目录的 `index.html`；不需要安装依赖或构建。

```sh
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000`。

## 发布网页

可把整个目录发布到 GitHub Pages、Netlify 或其他静态网站托管。入口是根目录 `index.html`，保留 `assets/` 与其他脚本的相对路径。

GitHub Pages：仓库 Settings → Pages → Deploy from a branch → main / root → Save。

## Demo 内容

七位住民、家具布置、独立楼层、日常活动与员工赚钱项目；5 级解锁三楼。支持自动存档、离线收益、短对话、游戏相册与拍照。

进度保存在当前浏览器，不跨设备同步。换托管域名也会使用独立存档，原域名的进度仍保留。界面里的“下载进度备份”可用于保留副本；目前没有自助导入界面。

体验版中只开放已匹配的部分家具朝向。反馈入口用于复制问题描述，不会自动发送。

## 文件说明

- `index.html`：网站入口，页面与浏览器标题为“花样年华照看所”。
- `assets/`：画面、人物、家具及音频。
- `world-*.js`：地图、动作与家具行为。
- `ui-*.js`：界面与玩法。
- `.nojekyll`：让 GitHub Pages 原样提供静态文件。

本仓库不包含玩家存档、聊天记录、访问凭证或开发过程草稿。素材及同人内容不附带开放许可。
